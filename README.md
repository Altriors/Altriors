## Featured Projects

### 1. Unified Hybrid Quantum Deep Q-Network Framework

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/Unified-Hybrid-Quantum-DQN)

A research-oriented reinforcement learning framework exploring classical and hybrid quantum approaches to Deep Q-Learning.

- Implements multiple reinforcement learning approaches, including DQN, Double DQN, Hybrid Quantum DQN and Rainbow.
- Integrates classical neural networks with parameterized quantum circuits.
- Uses a modular architecture for agents, models, replay buffers and experiment configurations.
- Explores reinforcement learning across environments such as CartPole, LunarLander and custom maze environments.

### 2. BinFlow — Civic Waste Management Platform

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/binflow)

A full-stack civic-tech platform designed to improve municipal waste complaint tracking and field-worker dispatch.

- Role-based access for citizens, administrators and field workers.
- GPS-based complaint reporting with image uploads.
- Real-time complaint status tracking.
- Integrated mapping, analytics dashboards and audit logs.
- Built using React, Node.js, Express, MongoDB Atlas, Leaflet and Cloudinary.

### 3. AI-Powered Interactive Virtual Companion

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/Stimulated_Chatbot)

An AI-powered virtual companion combining conversational intelligence with interactive 3D VRM avatar visualization.

- Context-aware conversational AI with character-specific personality.
- Persistent memory and conversation context management.
- Character emotional state and behavioral management.
- VRM-compatible 3D avatar integration.
- Modular frontend and backend architecture.

### 4. Geo-Fencing for Cattle Detection

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/cattle-geofence-project)

An AI-powered cattle monitoring application combining computer vision, mobile development and geofencing.

- Cross-platform mobile application developed using Flutter.
- YOLOv8-based cattle object detection.
- Monitors cattle movement and detects geofence boundary violations.
- Firebase integration for notifications and application data.
- Associated research published in JETIR Publications (2026).

### 5. PrivateManager — Personal Account Management

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/PrivateManager)

A Kotlin-based Android application designed to organize multiple email accounts and associated personal information.

- Organizes email accounts, passwords and personal notes.
- Tracks which email accounts are associated with different services.
- Helps manage account-related information for tools such as Antigravity.
- Tracks weekly reset schedules to make account management easier.

### 6. Digital Classroom Management System

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/digital-classroom-using-flutter)

A Flutter-based learning management application designed to connect teachers and students.

- Teacher and student account management.
- Course creation, enrollment and progress tracking.
- Firebase authentication and data management.
- Published research in HBRP Publications.

### 7. DevOps Automation with Telegram Alerts

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Altriors/Smart_Deployment_Notifier)

An automation project integrating CI/CD workflows with Telegram notifications.

- GitHub Actions-based CI/CD pipeline.
- Automated Telegram notifications for build and deployment events.
- Improved visibility into pipeline execution and status.
